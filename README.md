# Java & Spring Boot — Registro de aprendizaje

Repositorio donde voy subiendo los ejercicios y proyectos de mi camino hacia el desarrollo backend con Java. Cada carpeta es un proyecto independiente y están ordenadas según el avance: desde fundamentos del lenguaje hasta una API REST con seguridad, desplegada en la nube.

## 🛠️ Stack

- **Lenguaje:** Java 21
- **Framework:** Spring Boot 4 (Spring Web, Spring Data JPA, Spring Security)
- **Base de datos:** PostgreSQL
- **Frontend:** Angular (Como aspiro a ser Desarrollador Backend, el Front lo genero con ayuda de Claude y simulo comunicación como si fuera un Desarrollador Front y yo el Dev Backend).
- **Infraestructura:** Docker, Render, Netlify, Neon
- **Herramientas:** Maven, Postman, IntelliJ IDEA, Git

## 📂 Proyectos

| Carpeta | Descripción | Conceptos principales |
|---|---|---|
| `0-Procedural` | Ejercicios de programación estructurada en consola | Tipos, estructuras de control, arrays y matrices |
| `1-ObjetosHerencia` | Juego de batalla de robots por consola | POO, herencia, clases abstractas, enums |
| `2-ApiNormal` | Primera API REST con CRUD de entidades relacionadas | Controllers, services, repositories, JPA, relaciones |
| `3-ApiConSecurity` | API con autenticación y usuarios en base de datos | Spring Security, `UserDetailsService`, roles y permisos |
| `3.1-ApiConOAuth2` | Login con proveedor externo | OAuth2, login con Google |
| `3.2-PracticaApiSecurity` | Proyecto integrador: API + frontend desplegados | Seguridad, manejo global de errores, Docker, CORS, deploy |
